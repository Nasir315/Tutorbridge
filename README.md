# TutorBridge

An online tutoring platform where verified college students (engineering, MBBS) teach school kids in India and abroad, live and one on one.

This repo is a clickable front-end prototype made for an ideathon. All tutors, prices and class details are sample data.

## The problem

Good tutoring is expensive and hard to find. Many kids in India, and NRI kids abroad, need affordable and relatable help with school subjects. College students have the knowledge and free time but no safe, easy way to teach online. Parents also worry about who is teaching their child.

## The idea

- Tutors sign up with a college ID and a short demo lesson, then get a verified badge.
- Parents browse by subject, grade, board, language, price and time slot, then book a free trial class.
- Each class runs through a Meet or Zoom link generated inside the platform, so no personal contact details are shared.
- Sessions are recorded for safety. Parents get a dashboard with attendance, topics covered and tutor notes.
- Time zone matching lets tutors in India teach kids abroad during their evenings.

## What is in this prototype

| Page | What it shows |
| --- | --- |
| `index.html` | Landing page, how it works, safety, tutor sign-up pitch |
| `tutors.html` | Tutor browsing with a working subject filter |
| `dashboard.html` | Parent dashboard with next class, past classes, safety checks |

## Run it

No build step. Open `index.html` in a browser.
